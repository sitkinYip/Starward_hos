# Starward 极光玻璃 v2 原生设计规范

生效于 2026-11-25。只读设计源为 `questions-web` 的 `feat/ui-glass-v2`，冻结提交 `46188fc585026066bd1e92d52ce162c3bb827cde`。使用该提交的 `docs/design-system-aurora-glass-v2.md`、`.agents/skills/starward-aurora-glass-ui/SKILL.md`、`src/styles/foundation/tokens.css`、品牌 PNG 和正式业务组件。此提交是开发对照基线。线上版本与对照运行模式另记。

- 常规业务使用系统无衬线字体，题号、经验、等级、数量、计时和进度数字用 `fontFeature("'tnum' 1")`。Letter、Bless 和全屏媒体使用各自的阅读与观赏样式。
- 荣耀金用于奖品、成就、升级礼赞和终章徽章。普通控制、导航、通知和配乐使用冰蓝语义资源。移除装饰性英文 eyebrow 与重复副标题，保留状态、约束和辅助读屏文案。
- 圆角按 10vp 小徽标、16vp 控件和媒体、24vp 面板、999vp 圆形和胶囊。业务页面通过 ArkUI 资源引用共享语义色、圆角和动效参数。

## 原生材质与运动

| 层级 | 原生实现 |
| --- | --- |
| L0 | 视口底景延伸至透明系统栏，安全区约束可交互内容。启动窗口使用同主题底色与正式品牌图标。 |
| L1 | 场次、题卡、收藏、来信和护照使用轻量实体微透表面、细边与高光。长列表使用基础 ArkUI 容器，点光源以 API 26 的可用性、性能和实际表现为准。 |
| L2 | 悬浮导航、作答栏、Sheet 和弹窗沿用官方浮动、沉浸材质和系统转场。按 SDK 支持状态降级，用抬升表面保障对比度。 |
| 弹层蒙层 | 来信与答题断线恢复采用原生 `PromptAction`，答题提示和护照资料、密码、外观采用原生 `bindSheet`，均由根页面绘制延伸至系统栏的共享高斯蒙层。答对与终章演出复用同款蒙层。系统关闭模糊材质时使用深浅半透明令牌，仅使用系统原生蒙层的弹层也沿用该令牌。底层页面结构在遮罩后可见，触摸与返回动作由原生弹层或所属页面管理。 |

- 核对固定 API 26 的声明与官方指南后再选择 `HdsTabs`、`systemMaterial`、`pointLight`、官方分段器、`bindSheet` 和 `PromptAction`。采用 `StarwardRefresh`、`StarwardKeyboard`、`StarwardMotion` 等既有原生生命周期封装。
- Web 的 Motion Prompt 002 列表错峰、003 星芒爆发、007 数字递增、022 斜向扫光、051 底部 Sheet、060 胶囊分段以官方 ArkUI 过渡和动画映射。移植对应实现时保留源 MIT 署名。共享时长和曲线以冻结源码为准，同一弹层有单一外层进退场所有者。
- 主要动画作用于位移、缩放、透明度与绘制图层。减少动画时折叠非必要动效，持续效果随可见性停止。业务提交完成取自后端响应。
- 页签、相邻题切换及短入场统一用 240ms。场次和剧情用系统淡入淡出，设置用系统横向转场，Sheet 保留系统开合。切题的横向转场落定后再调整纵向阅读位置，保留每道题的原有状态与可操作范围。

## 页面结构

| 页面 | 直板端契约 |
| --- | --- |
| 全局壳 | 官方四键浮栏保留 regular/fill、键盘隐藏和原生触控反馈。头像直达护照，移除头像旧抽屉。仅启程显示两行身份和右侧 44vp 品牌星标。原生标题宿主透明，`THICK` 材质分别附在身份与品牌标记的形状内。其余根页从安全区标题起排。 |
| 登录与加载 | 复用 1:1 矢量星环徽记，四芒星、-14° 前后双弧、外公转与反向内轨。登录公转较慢。普通直板机键盘收起时，完整表单与帮助入口对齐底部安全区。帮助入口打开官方底部 Sheet，原位保留表单；短窗口、键盘和行内错误由原生滚动承接。保留密码保险箱、加载状态与失败重试。 |
| 启程 | 待赴／回响胶囊分段、横向星环场次卡。进行中卡片以主题冰蓝描边和固定光晕作柔和呼吸，系统减少动画时使用静态描边。等级限制、有效期、空态、滚动末项同步文案及官方刷新可达。 |
| 入场前场次简介 | 沿用共用玻璃头部，左侧返回，场次名居中。简介保留原生宽卡布局，手机上与顶栏左右对齐，条件逐行左标签右取值，长值可换行。已开始或已完成的场次直接恢复到相应内容。 |
| 答题 | 页顶与文本焦点常显的 `THICK` 胶囊由透明的 `NavDestination.title` 承载。下滑收起，轻微上滑恢复。内容可滚入胶囊与透明状态栏背后，静止页首和交互控件按真实安全区布局。四角星进度可读屏可导航，24vp 题卡只保留题号与唯一灯泡 Sheet。题干在上，16vp 透明配图在下。 |
| 作答与庆祝 | 独立悬浮作答栏按真实键盘视口避让。胶囊输入、选择和提交控件为 50vp，相邻控件间隔 10vp。未编辑的填空胶囊和折叠选择栏共用 ArkUI 背景玻璃和 UIDesignKit 静态边缘光。填空编辑时使用局部原生高斯模糊和主题抬升底色，保留同一输入实例。提交采用冰蓝主操作样式。选择用原生锚定浮层，在支持设备上使用 ArkUI `THICK` 沉浸材质，按可用高度展示，选完收起，已答与只读可打开和查看媒体，Radio 禁用。正确结算无阻断弹层时显示星芒和权威 EXP。自动切题显示「正在跳转下一题」，保留 1500ms 延迟。手动继续显示「下一题／继续」，点蒙层或空闲 3000ms 收起并保留本题。等级礼赞沿用「星穹加冕」。 |
| 答题线索 | 通关线索为列表，显示类型图标、标题、正文预览和数量小徽标。普通与组合线索使用圆角原生弹窗和共享玻璃蒙层。查看本场线索为 46vp 冰蓝星标胶囊，可拖拽贴边。配乐、来信和组合浮标避让作答栏。切到其他题时显示尚未打开的剧情线索，点击阅读按账号和场次记忆。 |
| 护照 | 星环头像、真实等级和经验、已解开／场次／收藏三项统计。资料、密码、外观、设置及退出分组，整行「设置」紧跟「外观」。护照底部提供隐私政策。设置保留原生旅途通知与订阅，底部展示安装包版本名和版本代码。草稿由功能页持有，裁剪与编辑 Sheet 同级挂载，账号切换和退出清理。 |
| 收藏 | 待领／已领胶囊分段与双列玻璃网格，原生左右滑动与分段同步，交互与启程和来信一致。待领高光与扫光，原生详情 Sheet。领取状态与敏感信息按现有权威字段呈现。 |
| 来信 | 旅途来信与星海信笺分段，独立来信页和答题内旅途弹层共用新版颜色、层级与未读状态。 |

原生折叠、分栏与窗口变化的专项验收在主体完成后执行。逐片使用相同内容和有效宽度对照深浅主题、关键业务状态和连续动效。实施状态、签名、交互和视觉证据见[逐状态验收表](feature-acceptance-matrix.md#2026-11-25极光玻璃-v2-实施前对照)。

用户确认星芒播放期间允许鸿蒙既有 `autoNext` 推进，切题后停止旧题演出。系统启动窗增强配置使用透明标志，API 20 起支持同进程随应用主题。冷启动主题按系统实际起窗条件核验。
